## 1.1. RPA60BT V2 Rackmount Brackets

Folder containing designs for the Rockville RPA60BT V2 sound system amp.  The brackets mount to the side of the stereo amp to allow for server rack mounting.

![alt text](image.png) 

### 1.1.1. Drawings

Contains the drawings for the parts I designed for the RPA60BT V2 brackets.  Made 2 versions with the intention that one would be 3D printed and the other would be made out of metal.


### 1.1.2. Pictures

Contains various screenshots I took during this project that I found some importance/cool factor to.

### 1.1.3. 3D Files

Contains the solidworks files for both PLA and Metal brackets, should fit a 1U nice

### 1.1.4. STL Files

Contains the STL files used to print the PLA and if you want the metal versions.
